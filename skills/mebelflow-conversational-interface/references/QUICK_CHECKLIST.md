# MebelFlow UI Quick Checklist

## До реализации

- [ ] Определена одна пользовательская задача
- [ ] Определён один основной CTA
- [ ] Известен текущий этап flow
- [ ] Определены mobile constraints
- [ ] Определены loading/error/offline states
- [ ] Указано, что является AI и что предварительно

## Conversation

- [ ] Голос имеет текстовую альтернативу
- [ ] Транскрипт видим
- [ ] Интерпретация понятна
- [ ] Ошибочная команда не применяется
- [ ] Undo доступен
- [ ] Следующий вопрос контекстен

## Scheme

- [ ] Размеры читаемы
- [ ] Выбранный модуль заметен без зависимости от цвета
- [ ] Остаток показан
- [ ] Конфликт привязан к месту
- [ ] SVG доступен screen reader
- [ ] Нет тяжёлого 3D

## Trust

- [ ] Цена обозначена как предварительная
- [ ] Disclaimer видим до финального действия
- [ ] Ошибка объясняет следующий шаг
- [ ] Данные не теряются
- [ ] Запись голоса не начинается скрыто

## Quality

- [ ] Design tokens
- [ ] Нет generic AI gradient/card soup
- [ ] Touch targets ≥44px
- [ ] Focus visible
- [ ] Contrast AA
- [ ] Reduced motion
- [ ] Android 360×800 проверен
