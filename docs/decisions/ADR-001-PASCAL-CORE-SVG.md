# ADR-001: Pascal-style Core + собственный SVG Renderer

**Статус:** Accepted  
**Дата:** 2026-08-02

## Контекст

Для разговорного конструктора нужна структурированная сцена:

- узлы;
- create/update/delete;
- история;
- metadata;
- валидация;
- undo/redo.

Pascal Editor предоставляет близкую архитектуру, но полный редактор и WebGPU для MVP избыточны.

## Решение

Использовать вариант B:

- провести spike `@pascal-app/core`;
- создать собственный `SceneStoreAdapter`;
- не связывать доменную модель с Pascal;
- использовать собственный SVG Renderer;
- использовать Zustand/Zundo как fallback;
- не загружать полноценный Pascal Editor.

## Последствия

### Плюсы

- быстрее создать надёжное состояние;
- undo/redo;
- меньше собственного инфраструктурного кода;
- возможность будущего viewer;
- независимость через adapter.

### Минусы

- требуется spike;
- возможна несовместимость API;
- дополнительная зависимость;
- риск bundle size.

## Критерии принятия Pascal Core

- MIT или совместимая лицензия;
- browser-ready;
- tree-shakable;
- нет обязательного WebGPU;
- bundle impact приемлем;
- API стабилен;
- работает через adapter;
- Android не деградирует.

Если критерии не выполнены — использовать Zustand/Zundo без Pascal.
