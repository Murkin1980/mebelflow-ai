# ADR-003: LLM не управляет геометрией напрямую

**Статус:** Accepted  
**Дата:** 2026-08-02

## Решение

LLM может вернуть только команду из белого списка.

Команда проходит:

1. schema validation;
2. domain validation;
3. layout rules;
4. idempotency;
5. state update.

LLM не вычисляет итоговое положение без проверки движком.

## Причина

- предсказуемость;
- тестируемость;
- безопасность;
- повторяемость;
- снижение стоимости;
- исключение галлюцинаций.
