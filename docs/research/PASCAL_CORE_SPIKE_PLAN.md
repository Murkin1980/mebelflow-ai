# Pascal Core Spike Plan

## Цель

Установить, можно ли безопасно использовать Pascal Core как внутренний scene store без полного редактора и WebGPU.

## Проверки

1. Пакет устанавливается отдельно.
2. API создания узлов доступен.
3. Можно определить мебельный тип.
4. Metadata сохраняется.
5. Update не требует renderer.
6. Undo/redo работает.
7. Состояние сериализуется в JSON.
8. Tree shaking работает.
9. Bundle impact измерен.
10. Chrome Android запускается.
11. Нет обязательного WebGPU.
12. Лицензия совместима.
13. API можно скрыть за adapter.
14. Ошибка пакета не ломает доменный reducer.

## Benchmark

Сравнить:

- Pascal Core;
- Zustand + Zundo;
- собственный reducer.

## Решение

### USE

Если Pascal выигрывает и не добавляет лишний runtime.

### ADAPT

Если полезны отдельные идеи или утилиты.

### REJECT

Если пакет привязан к 3D, нестабилен или тяжёл.
