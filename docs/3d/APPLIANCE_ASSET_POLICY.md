# Appliance asset policy

External sinks, faucets and appliances may enter the public MebelFlow widget only when all of these checks pass:

1. The primary source page identifies the author and license.
2. The license is CC0-1.0 or CC-BY-4.0 and permits commercial web use and redistribution.
3. CC-BY attribution is stored beside the asset and rendered in the product credits.
4. The file is converted to GLB, scanned locally, and contains no scripts or external network references.
5. Dimensions are normalized to millimetres with X=width, Y=height and Z=depth in Three.js.
6. Textures are embedded or copied into the owned asset directory.
7. The optimized asset stays within the widget performance budget and retains a box fallback.

“Free download”, editorial-only, personal-use-only, no-derivatives, non-commercial, unclear-license and source-page-only assets are rejected.
