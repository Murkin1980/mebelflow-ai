# Pricing Engine

Детерминированный расчёт предварительной стоимости Stage 6. Поддерживает tenant-стратегии `per_meter`, `per_module` и `hybrid`, версию формулы, диапазон неопределённости и разбивку по нижним/верхним модулям, фасадам и фурнитуре.

Результат всегда имеет валюту KZT, статус `preliminary` и обязательный disclaimer. AI не может менять конфигурацию tenant и не участвует в арифметике цены.
