# Pilot Analytics

Stage 9 readiness core: tenant/embed configuration, privacy-safe analytics, sanitized errors, cost dashboard, controlled/real session registry, interview notes, funnel report and go/no-go gate.

`decidePilot` возвращает `WAITING_FOR_DATA`, пока не зафиксированы минимум 20 controlled sessions, 5 real prospects и 5 интервью. Тестовые данные проверяют формулы, но не считаются фактическими результатами пилота.
