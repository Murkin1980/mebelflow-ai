# Voice Input

Детерминированное ядро Stage 5 для голосового ввода. Пакет не зависит от браузерного MediaRecorder и конкретного STT API: адаптер передаёт аудиобуфер в `VoiceSession`, а `SttProvider` возвращает проверяемый транскрипт.

Поток: явное разрешение → запись → стоп → STT → видимый/редактируемый транскрипт → подтверждение → Intent Parser → безопасное применение. При отказе микрофона, offline и ошибке STT всегда доступен текстовый путь; повторная отправка записи происходит только по явному `retry()`.

`VoiceCostLedger` считает запросы, оплачиваемые секунды и ориентировочную стоимость в KZT. Реальный STT-провайдер, секреты и production-запись в Stage 5 не подключаются.
